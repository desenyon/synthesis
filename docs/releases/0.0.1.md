# Synthesis 0.0.1 — development prerelease

An early Apple Silicon macOS build for trying the connected worldbuilding studio. This is a development checkpoint, not the 1.0 public product launch.

- Sidebar narrowed from 312 to 284 points, preserving its design. Hover cleanup, composer focus feedback, growing input and workspace/companion transitions refined.
- Graph zoom now preserves the focal point for buttons and gestures, including after Fit. Selecting a node no longer automatically refits the viewport; labels scale with their cards.
- Canvas relationships remain attached to their world entities. Click a relationship label to edit it or explicitly hide it on the board. Free arrows remain drawings until converted through review.
- Timeline proposals can create a branch, nested periods and sourced events together. Events without a source create a draft document on acceptance. History shows the hierarchy, including empty branches.
- Accepted map creation/marker proposals select their affected map. Shared world refresh keeps records, Review and spatial views current.
- Every message identifies the workspace active at submission. Codex memories, external memory import, host skills and web search are explicitly disabled. Only required authentication/runtime environment variables are inherited; world-scoped retrieval and explicit canon approval remain enforced.

## Installation

Requires Apple Silicon and macOS 14 or later. Unzip and move Synthesis.app to Applications. This build is **ad-hoc signed and not notarized**; macOS may block it. If you choose to trust this prerelease, use macOS Privacy & Security → Open Anyway. Do not disable Gatekeeper globally. Source builds remain available with `./scripts/build.sh release`.

The ZIP contains only the application. User worlds, account credentials and local verification databases are not included. SHA256SUMS.txt and third-party notices accompany it.

## Verification and limitations

Verification is recorded in `docs/STATE.md`. Automated harness tests use stand-in executables, not paid model calls. Background native captures verify settled layout and engine behavior; they do not certify foreground trackpad feel, animation smoothness or VoiceOver. This release has not been tested on an Intel Mac or macOS 14 hardware. No live subscription request or notarization was performed for this checkpoint.

Synthesis supports validated worldbuilding proposals, not unrestricted executable agent UI or autonomous control. Canon always requires the creator's explicit approval. Advanced map generation and full spatial power-system simulation remain future work.
