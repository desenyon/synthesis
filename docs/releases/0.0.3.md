# Synthesis 0.0.3

What-if worlds, technique trees, Atlas regions, new Timeline views, stronger Review checks, crash recovery and Finder integration.

## Highlights

- **What-if worlds.** World menu → *New what-if from …* copies the open world. Explore freely, then *Send changes to …*: rewrites, new records, relationships and events become one proposal in the original's Review. Text edited in both worlds is listed and never sent. Nothing in the original changes until you accept it, and accepted changes are drafts.
- **Technique trees.** In Mechanics, tick what a technique or progression step requires first. The tree is drawn for you; loops are refused.
- **Atlas regions.** *Draw region*, click around an area, drag the points to reshape. Regions link to records and can be shown or hidden separately from markers.
- **Timeline.** Detailed, Compact and By era views; move events earlier or later.
- **Review checks** for one-way relationships recorded both ways, dates out of order and tag spellings, with a reversible *Merge tags*.
- **Crash recovery** for editor text that never reached a saved revision.
- **Finder.** Double-click a `.synthesis` file to open it as a new world (after a confirmation).
- **Generate with Codex** in the illustration library: one explicit request per press, carrying only your description.

Fixes: Return now completes the welcome sheet; ⌘K runs a matching command instead of capturing typed text. Full list in [CHANGELOG](../../CHANGELOG.md).

## Install

Apple Silicon, macOS 14 or later. Download `Synthesis-0.0.3-macos-arm64.zip`, unzip, and move **Synthesis.app** to Applications. The app is **ad-hoc signed and not notarized**, so macOS blocks the first launch: open it once, then choose *System Settings → Privacy & Security → Open Anyway*. Do not disable Gatekeeper globally. Check the download against `SHA256SUMS.txt`.

Existing worlds upgrade in place (migrations 0011–0013 are additive). The ZIP contains only the app: no worlds, credentials or test databases.

## Verified

158 native tests in 40 suites, strict lint and optimized build; 12 Canvas tests and type check; the foreground interaction self-test (19 real pointer and key checks); live window captures in dark and light; an Accessibility label sweep of every workspace; background captures of every new state at 1440×900 and 1024×768.

## Known limits

A live Codex image generation has not been run (it uses subscription allowance). VoiceOver, trackpad feel and animation pacing are not certified. What-ifs merge two ways only; there is no three-way text merge. Tested on the development Mac only.
