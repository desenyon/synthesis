# Synthesis 0.0.2

A follow-up to 0.0.1 focused on connected editing, recovery and Canvas reliability. The original release remains intact.

- Preserve unfinished responses and unsent prompts on Stop; retry keeps newer draft text. Continue can reference the saved incomplete reply. Transcript follow pauses while you read older messages.
- Requests include the current workspace, selected entity, map/board and history branch. Navigation makes no model calls. Subscription tools, host configuration and unrelated worlds remain outside the agent boundary.
- Review edits to existing events, history branches/periods, maps and relationship labels. See before/after fields; stale changes are rejected. Accepted chronology returns to All history and map edits refresh the correct Atlas.
- Edit/collapse nested chronology; contextual chat floats above secondary workspaces and keeps its width. Canvas chat retains docking and compact takeover.
- Fix Canvas viewport loss after initial fitting and repeated approval/reload. Relationship arrows stay record-owned; close parallel links and basic intervening-card detours are legible. Graph zoom retains its focal point.
- Isolate provider/model settings per app instance so background checks cannot affect an open workspace.
- Preserve the accepted narrower sidebar and refresh eight README screenshots.

Validated: 140 native tests/30 suites, strict lint, optimized build; 11 Canvas tests, TypeScript and bundle build; 28 native/WebKit integration checks; 48 inspected background native captures, plus 16 inspected captures from the extracted distribution ZIP. One approved real Codex request used an isolated fixture universe, cited lore and staged a proposal without applying it. It emitted one completed update, not token streaming.

Apple Silicon, macOS 14+; tested on the current development Mac only. Ad-hoc signed, **not notarized**. Physical trackpad/VoiceOver and animation pacing, live CLI cancellation and large dense-board behavior remain unverified. On-demand subscription images, arbitrary generated UI, canon branch merging and a full spatial techniques/map engine remain incomplete. An early release, not yet the 1.0 launch.
