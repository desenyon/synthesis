# Connected design direction

Preserve the accepted native graphite foundation. The latest owner refinement replaces the large onboarding composer with distinct workspaces and real content.

- 56-point integrated header, no separate OS title bar. World identity and independent AI Assisted / Manual control remain persistent.
- 220/56-point labeled/collapsed navigation. Workspace identities, worldbuilding category lenses, recent conversations and tooltips.
- Full Conversation workspace with a readable message column and bottom composer. Canvas companion docks into a 320–460-point resizable region; collapsed composer is approximately 500×74 points with explicit provider disclosure.
- Canvas is a saved creative arrangement; Graph is automatically derived. Real cards are 300 points wide with 17-point titles, 14-point descriptions, 12-point metadata, selection, connection handles and source-open actions. Empty boards remain empty.
- Charcoal surfaces #17191C / #1D2024 / #262A30, secondary text #BEC5CE, tertiary #929CAA, restrained cyan #A9C7DB. Character/faction/power types use muted semantic accents. Corresponding light tokens cover the entire app.
- No oversized ASCII background or decorative starter connections. Optional local world-cover and card artwork supplies identity. Fine grid, readable directed relationship lines and inspectable labels support spatial reading.
- Short transitions, local input state, cached images and deferred viewport persistence. No looping animation or performance guarantee without measurements.

The previous canvas UI study is historical. The connected implementation must never hide save failures or present authored capture fixtures as generated AI output.
