# One history across the studio

Use the workspace's **Back** and **Forward** controls, or **⌘[** and **⌘]**, to revisit documents, maps, boards, conversations and tools. The same commands are in the native View menu. Right-click either arrow to jump to an earlier or later visit. Record breadcrumbs use the same history.

Visits remember entity Overview/Sections/Mechanics pages, both editor panes, Timeline branches, Settings sections and search, Library category/search/filter/sort, Review tabs and focused proposals, and the optional inspected object. Atlas also retains [map framing and layers](ATLAS_NAVIGATION.md). Switching tool subpages creates a visit; typing search text updates the current visit rather than adding one per keystroke.

Returning resolves current saved sources, not an old copy of lore. Both editors must save before navigation. A failed save leaves the current visit and both history directions intact. An archived destination is skipped; an optional inspected source that disappeared clears without making the workspace unreachable. Navigation never restores older canon or changes assistance permissions.

Opening a new destination after going Back starts a new path and clears Forward. Repeated visits to the same address add nothing. The history is limited to 100 entries in each direction and lasts for the current app session; complete restart restoration is tracked separately at expansion #33.
