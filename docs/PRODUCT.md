# Synthesis product

A native worldbuilding studio: conversation, writing and spatial exploration are views of one universe. The creator owns all lore and deliberate canon.

Assisted entry: dedicated Conversation with saved history, local lore references and explicit external-provider disclosure. Manual independently blocks model requests while preserving all creative tools. Canvas is a manually curated board; Graph is an automatic relationship view that can be copied into Canvas. Library, Timeline and Atlas share source records.

Daily journey: create a world → capture or write a draft → add it to a board → link actual entities → navigate the graph or source record → revisit saved content. Guidance is optional, and a new world is genuinely empty. User-authored and AI-proposed drafts remain distinct from accepted canon; review shows the old accepted text and proposed draft before explicit approval.

Removal is always reversible: archive with Undo, restore from Library, conversation history or the board menu.

Current visual contract: one graphite design system with a complete light counterpart, a single bar per workspace, readable sans-serif hierarchy, restrained semantic colours, real entity cards and optional world artwork. No permanent assistant overlay, fake starter lore, decorative edges, analytics or preview-only production labels.

The current canvas uses the owner's node-workspace reference: compact graphite cards with inset image previews, colored relationship ports, curved typed connections and edge-docked tools. Excalidraw provides the editing engine beneath Synthesis presentation. Generated illustrations are optional assets chosen explicitly; images imply no canon. The exact reference match remains under review, and exports currently use engine-rendered card styling.

## Connected studio refinement — 2026-11-15

The assistant is subscription-only (Claude Code / Codex). It receives world records plus a bounded structured index of relationships, chronology and boards. The creator can review proposals to create a board, place linked records, add map markers, link documents and create draft rules, alongside existing lore actions. Accepting a proposal is not canon approval. All manual work remains available with AI off.

Canvas distinguishes board-only text/drawings from Library records. Saving board text as an idea creates a source record and replaces it with a linked card. Relationships are shared with Graph and editable through native inspection. Entity details expose rules for manual addition/editing; the dedicated power-system lab is later work.

## Studio refinement, 2026-11-15

The world menu opens a Worlds workspace; users can search world names, create worlds, save portable snapshots and reopen independent copies. First-install setup is separate from full-page application/current-world settings. Content workspaces share optional contextual conversation. Systems encompasses factions and other organizations without imposing a taxonomy. Timeline now supports nested periods and branches with sourced events and explicit reviewed agent creation. These groupings do not constitute branching canon. Runtime image generation, living entity schemas, power-system canvas and coherent generated maps remain unfinished requirements, tracked in NEXT_PASS.md.


### Reviewed editing and recovery

The assistant can propose revisions to existing event dates/placement, history branch/period metadata, map identity/hierarchy and relationship labels. Review shows changed fields and rejects stale snapshots. Acceptance refreshes connected views; it does not establish canon. Manual editing remains available. Interrupted replies retain useful prose, retry preserves new draft text, and each request uses the workspace/selection visible when sent. History trees can be collapsed and edited without losing sourced events.
