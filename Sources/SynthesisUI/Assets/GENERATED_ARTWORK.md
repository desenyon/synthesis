# Optional GPT artwork

Generated 2026-11-13 with the built-in GPT image-generation tool at the owner's request.

- `drowned-atlas-gpt.jpg`: top-down illustrated coast, islands and an inland sea; no place labels.
- `cartographer-gpt.jpg`: fictional cartographer above a drowned coastal city.

Selectable through Atlas and Canvas illustration pickers. No user image is replaced automatically. These are illustrative assets, not canon or live model responses. They ship locally and require no network request to display. Generating new images from inside Synthesis is not implemented by these assets.

The shipped files are JPEG encodings of the generated PNGs to keep local board payloads small; the artwork itself is unchanged.
